# Data sources

- `algeria-communes-58-wilayas.json` is the 58-wilaya structure from [wadiemendja/algeria-communes-wilayas](https://github.com/wadiemendja/algeria-communes-wilayas), containing 1,541 communes mapped to wilaya and daïra. The 58-wilaya version is intentional because the Ecotrack template uses wilaya codes 01–58.
- `../assets/templates/upload_ecotrack_v31.xlsx` is the supplied Ecotrack upload template and is kept unchanged as the append source.
